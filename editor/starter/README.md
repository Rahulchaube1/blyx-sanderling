# Sanderling starter

Choose a cache serving mode from stored age, local elapsed time and grace policy.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Sanderling** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
1
13
3
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/sanderling) · [View the release](https://github.com/Rahulchaube1/blyx-sanderling/releases/tag/v0.1.0)
